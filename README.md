# Praktikum Pemrograman Berorientasi Objek (PBO) - Kelas E1

Repositori ini berisi kumpulan tugas, latihan, dan materi untuk mata kuliah **Praktikum Pemrograman Berorientasi Objek (PBO)** pada Semester 4. Seluruh kode yang ada di dalam repositori ini ditulis menggunakan bahasa pemrograman **Java**.


## 📁 Struktur Repositori

Repositori ini terdiri dari beberapa folder yang mewakili setiap pertemuan praktikum, tugas, dan ujian, di antaranya:

### 📖 Pertemuan & Latihan
- `Pertemuan1` - `Pertemuan6`: Berisi materi, kode latihan, dan eksperimen yang dilakukan saat sesi praktikum rutin.
- `Pertemuan4 - Tugas`, `Pertemuan5 - Latihan`: Tugas tambahan atau latihan spesifik untuk pertemuan tertentu.
- `KelasPertemuan13`: Materi atau tugas untuk kelas pertemuan ke-13.

### 📝 Tugas Praktikum (PBO07 - PBO12)

### 🎓 Ujian (UTS)

## 🛠️ Teknologi yang Digunakan

- **Bahasa Pemrograman**: Java
- **IDE / Text Editor**: Visual Studio Code (beserta Extension Pack for Java)
- **Struktur Proyek**: Setiap folder biasanya terdiri dari struktur standar Java (`src/` untuk source code, `bin/` untuk hasil kompilasi/class files).

---

## 🚀 Cara Menjalankan Kode

1. Pastikan **Java Development Kit (JDK)** sudah terinstal di komputer Anda.
2. Clone repositori ini ke komputer lokal Anda:
   ```bash
   git clone <url-repositori-ini>
   ```
3. Buka folder repositori di **Visual Studio Code** atau IDE Java lainnya.
4. Masuk ke salah satu folder pertemuan atau tugas yang ingin dijalankan (misal: `Pertemuan1`).
5. Jalankan file `.java` yang memiliki metode `main` melalui IDE (Run Java) atau lakukan kompilasi manual menggunakan terminal:
   ```bash
   javac -d bin src/*.java
   java -cp bin MainClassName
   ```
